# Sovereign Source 2-Minute Demo Script

## Setup

This is a simulated demo. No real controlled technical data is stored here.

## Talk Track

0:00 - Buyer starts with a controlled titanium aerospace bracket. The package needs 5-axis titanium capability, tight tolerance, AS9100, ITAR evidence, JCP DD2345 evidence, CMMC Level 2 evidence, and buyer-side classification approval.

0:20 - Compliance reviewer checks the classification gate and evidence queue. The language is evidence-backed: "evidence valid," "manual review required," or "access suspended."

0:45 - Buyer runs deterministic matching. Vector Aero is eligible. Keystone needs manual review for CMMC. Other suppliers are blocked by expired evidence, missing evidence, process mismatch, material mismatch, tolerance mismatch, or capacity confidence.

1:15 - Buyer releases an RFQ invite to eligible suppliers. Files are not sent as attachments; access is scoped to the work package and invite.

1:35 - Supplier opens the portal, views the data-room file list, and can quote, decline, or no-bid. Document views and downloads create audit events.

1:55 - Buyer exports the audit trail showing who saw what, when, and why.

## Close

The pilot value is controlled RFQ routing with evidence-backed supplier qualification, not automated legal compliance.
